### 阶段 1 决策

公开列表页和详情页在不登录的情况下可以暴露足够字段，已进入阶段 1 开发。

当前状态：

- Wellcee 真实列表来自公开 API：`POST /api/v3/frontend/house/get`。
- 筛选项来自公开 API：`GET /api/house/filterType?cityId=15102233103895305&lang=1`。
- 浦东 `districtId` 为 `15133101536753307`。
- 整租 `rentTypeId` 为 `15103931190241306`。
- 长租 `timeTypeId` 为 `15103937805971616`。
- 1 居室使用 `bedroom: [1]`。
- 当前阶段 1 只抓取 Wellcee API 第一页。
- API 返回浦东 + 3500-6000 + 整租 + 长租 + 1 居室总数约 789，第一页 20 条。
- 详情页 URL 使用 canonical 格式：`https://www.wellcee.com/rent-apartment/{id}`。
- 去重 ID 使用详情 URL 末尾的数字 ID。
- 严格过滤后的样本会导出到 `data/validation/phase1_validation_sample.csv`。
- 所有候选及排除原因会导出到 `data/validation/phase1_filter_candidates.csv`。
